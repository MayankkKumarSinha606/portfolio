Developed a group IoT project that enables remote control of a garage door model using a smartphone over Wi-Fi through the Blynk IoT platform.

  • Remote garage door control through the Blynk application.
  • ESP32-based Wi-Fi connectivity.
  • Servo motor control using Arduino code.
  • Team coordination, risk assessment, and documentation.

Technologies: ESP32, Arduino IDE, C++, Blynk IoT, Wi-Fi, Servo Motors
